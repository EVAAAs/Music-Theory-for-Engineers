# 练习答案

## Ch00 导言

<a id="ch00"></a>

**选择题**（B、C、B、C、B）：

1. B。声音的物理本质就是空气的压强波动；其余选项分别是粒子、电磁、热，都不是声学对象。
2. C。音色 = 同一基频上叠加的不同谐波比例，即频谱形状。
3. B。A4=440 Hz 是 1939 年 ISO 的调音约定，不是由物理定律决定的常数。
4. C。频率翻倍（八度）= $1200\log_2 2=1200$ 音分。
5. B。中央 C 记 C4，MIDI 编号 m=60；A4 才是 m=69。

**问答题**：

1. 因为音乐是"在时间中有组织的频率结构"：音高 = 基频、音色 = 频谱、音程 = 频率比、音律 = 频率轴的离散化、调式/调/转调 = 频率集合上的结构关系。把"频率的语言"逐条展开，就是全书正文。
2. 三块基石：波动方程（为什么弦/管只产生 $f_n=nf_1$ 的谐波序列——乐音的物理起源）；傅里叶变换（任何声音是频率分量叠加，音色 = 频谱，乐音/噪音 = 离散谱/连续谱）；对数频率轴（人耳按比例感知，音乐的"距离"是比值，乘法变加法）。
3. 十二个半音均匀铺在一圈钟面上，移调就是把整圈钟拨一格。这个比喻想说：乐理不是一堆需要死记的约定，而是被声学与几何决定、可以自己推出来的结构——为什么是 12、为什么五度重要、为什么移调听起来一样，都来自这一个几何事实。

## Ch01 波动方程与驻波

<a id="ch01"></a>

**选择题**（A、B、B、B、A）：

1. A。两端固定的弦，本征频率是 $f_n=nf_1$（n 为正整数），基频与各阶泛音成整数比。
2. B。$f_1=c/2L$：弦长减半，基频翻倍——弦越短音越高。
3. B。"一个音是复合音"不是经验约定——边界条件决定了振动只能是整数倍本征频率的叠加，复合是必然。
4. B。音色的全部信息都在各阶驻波的振幅序列 $\{A_n\}$ 里（相位也有作用，振幅是主项）。
5. A。乐音 = 周期信号（整数倍本征频率，离散谱）；噪音 = 非周期信号（频率不成整数倍）。

**问答题**：

1. 两端固定的弦，波长必须满足驻波条件，因此允许的频率只有 $f_n=nf_1$ 这一串整数倍频率。基频是这套序列的"最小公倍数"，其余泛音都落在它的整数倍上，所以音高由基频决定。
2. 泛音振幅 $A_n$ 通常随 n 增大而衰减（高阶驻波更难激发、能量更分散）——这是后文"谐波重合法则"里"低序数重合更强"的物理来源。
3. 按弦位置 = 改变有效弦长 L：L 变短，$f_1=c/2L$ 升高，所以同一根弦按得越短音越高。弦乐、吉他、二胡都靠这个动作改变音高。

## Ch02 傅里叶变换：音色 = 频谱

<a id="ch02"></a>

**选择题**（B、B、A、B、B）：

1. B。乐音是周期信号，傅里叶级数给出离散谱（一根根等距的谱线）。
2. B。拍频 = 两个近频叠加时振幅以差频涨落。
3. A。音色 = 频谱形状，即谐波振幅序列 $\{|c_n|\}$。
4. B。拍频 = 差频 = $|f_1-f_2|=|440-442|=2$ Hz。
5. B。非周期信号（噪音）的频率分量连续铺满，谱是连续的。

**问答题**：

1. 乐音是周期信号，其频率分量必然是基频的整数倍，谱线离散；噪音是非周期信号，频率分量连续铺满，谱是连续的。周期 ↔ 离散谱、非周期 ↔ 连续谱是一对。
2. 傅里叶变换把声音拆成频率分量（分析方向）；反演（合成方向）说明这些分量可以叠加回去重构原声。它保证"频谱"不是丢了信息的近似，而是完整描述了信号。
3. 两个接近的频率叠加，振幅以它们的差频为周期起伏——这就是拍频。差频很小（<20 Hz 左右）时它不再被听成两个音，而是同一音上的强弱起伏，这是后文粗糙度（Ch9）的伏笔。

## Ch03 对数频率轴

<a id="ch03"></a>

**选择题**（B、C、B、B、A）：

1. B。人耳近似按比例感知频率（八度翻倍听感"距离"不变），所以音乐的距离是比值，用对数轴。
2. C。一个八度 = $1200\log_2(2)=1200$ 音分。
3. B。A4=440 Hz 是历史约定（ISO 定），不是物理常数；C4=261.63 Hz 是它的派生刻度。
4. B。中央 C = C4 = MIDI 60（A4 才是 69）。
5. A。平均律下每个半音恰好 100 音分（一格 $2^{1/12}$）。

**问答题**：

1. 对数轴上频率的乘法变加法：音程（比值）变成距离，移调（整体乘一个因子）变成平移，转调（换基准）变成移动基准点。乐理里的"距离"因此全部有了几何意义。
2. A4=440 Hz 是调音/调频的基准零点（所有音高用它标定）；C4（中央 C）是记谱的中央参照（谱表、音名编排的中枢）。一个是物理调音基准，一个是记谱参照，角色不同。
3. 平均律把八度切成 12 个完全相等的半音，每个音名钉死一个频率，移调后仍能落回同一套格子；纯律用各种小整数比，同一个音名（如 #C）可以对应多个频率，无法做到"一名一频"。

## Ch04 纯律

<a id="ch04"></a>

**选择题**（A、A、A、C、B）：

1. A。纯律大三度 = 5:4（386.31 音分）。
2. A。普通音差 = 81:80 ≈ 21.51 音分。
3. A。Ptolemaic 大调音阶第一级音程（C–D）是大全音 9:8 = 203.91 音分。
4. C。三个大三度（5:4 叠三次）= 125:64，比两个八度（2×2=4=128:64）低 41.06 音分（diaschisma），三度不闭合。
5. B。纯律各音程都是局部最优的小整数比，但整套 12 音网格不自洽——不能整体平移而不漂移。

**问答题**：

1. 纯律对每个单音程用最小整数比（八度 2:1、五度 3:2、大三度 5:4……），单个音程都是"最准"的；但这些比组合起来凑不成一个自洽的 12 音格，同度会有多种长度、整套音阶平移后走样。
2. 大三和弦 4:5:6：根音 4 谐波 = 三音 5 谐波（三音音高重合），根音 2 谐波 = 五音 3 谐波（五音重合）。重合的谐波序数越小，听感越融合。
3. C→G→D：C×3:2=G，G×3:2=D，得到 D = 9:4 = 81:32（记到八度内 81:64）；C→A→D：C×5:3=A，A×3:2=D，得到 D = 5:2 = 5:2（八度内 5:4）。两条路径算出的同一个 D 相差 81:80 = 21.51 音分——这就是普通音差，同名音二义性的来源。

## Ch05 五度相生律

<a id="ch05"></a>

**选择题**（B、A、B、B、B）：

1. B。毕氏音差 = 23.46 音分（$12\times701.955-7\times1200$）。
2. A。狼五度 = 678.49 音分，比纯五度窄 23.46 音分。
3. B。五度相生律的大三度 = 81:64 = 407.82 音分，比纯律 5:4 高 21.51 音分。
4. B。$(3/2)^{12}/2^7=531441/524288=1.01364$——"12 个五度 = 7 个八度 × 1.01364"。
5. B。五度相生律对五度绝对忠实（只认 3:2）；代价是三度偏了 21.51 音分。

**问答题**：

1. 每个五度 = 701.955 音分，12 个共 8423.46 音分；7 个八度 = 8400 音分。两者不相等：12 个五度比 7 个八度高 23.46 音分，所以沿五度链走 12 步回不到起点（螺旋不闭合）。
2. 五度链走 12 步多出 23.46 音分。要让五度链在 12 个音级上"闭合"，最后一个五度只能被压窄这 23.46 音分，得到 678.49 音分的五度——比正常五度窄，听感刺耳，史称狼五度。
3. 五度链上两格（两五度）之间是 90.22 音分的自然半音（如 E–F）；升号音与降号音之间（如 #C–D 的"变化半音"路径）经过更多步，是 113.69 音分。两条半音路径步数不同，数值就不同——这来自五度链在 12 音级上无法均匀闭合的同一个缺口。

## Ch06 十二平均律

<a id="ch06"></a>

**选择题**（A、B、A、B、B）：

1. A。平均律半音恒为 100 音分（$2^{1/12}$）。
2. B。平均律五度 = 700 音分，比纯五度 701.955 音分窄 1.96 音分。
3. A。$\gcd(7,12)=1$：连续加 7 模 12 会走遍全部 12 个格子，五度圈一次走全——这是"为什么是 12"里生成元 7 的关键性质。
4. B。平均律大三度 = 400 音分，比纯律 386.31 音分宽 13.69 音分。
5. B。$\log_2(3/2)\approx 7/12$，分母 < 41 的连分数逼近里 12 是最佳且可行的，所以是 12。

**问答题**：

1. 平均律把五度压窄 1.96 音分、把三度放宽 13.69 音分，用这点"处处微小误差"摊平了毕氏音差（23.46 音分），换来的是：任何移调（平移 $2^{k/12}$）后所有音程不变——移调自由。
2. "7 和 12 互素"意味着连加 7（模 12）永远走不回头地遍历 12 个格子：从 C 出发，加 7 = 纯五度 G、再加 7 = D……12 步恰好每个音级各到一次，回到 C。这就是五度圈完整的数学保证；若生成元与 12 不互素（如加 6），只能走 2 格就循环了。
3. 把 12 个半音画成一圈钟面，每个刻度 = 一个半音；移调 = 把整圈钟拨一格（平移算子 $T_k$）。音程不变 = 拨完一格后刻度间距离不变。钟面转格就是 $\mathbb{Z}_{12}$ 平移的直观版本。

## Ch07 三种音律的比较

<a id="ch07"></a>

**选择题**（B、A、B、B、A）：

1. B。三律都从 3:2 出发，所以五度（G、D、F 系）三律几乎一致，差别集中在三度/六度（E、A 系）。
2. A。平均律的自然半音（E–F）= 100 音分；五度相生律 90.22c、纯律 111.73c。
3. B。纯律 #C 有二义性：作为变化半音可能是 70.67 音分（25:24）或 111.73 音分（16:15）——所以纯律对 #C 不做一一对应断言。
4. B。五度相生律的变化半音（C–#C）= 113.69 音分（2187:2048）。
5. A。三律都基于 3:2 的纯五度，所以五度（G、D、F）三律几乎一致。

**问答题**：

1. 纯律每个音程都是"局部"最准的小整数比，所以单音程听感好；但这些局部最优凑不成自洽的 12 音格，整套音阶一平移就漂移（整体不自洽）。平均律恰好相反：单音程都差一点点，但整体可移调。
2. "自然半音"（E–F）与"变化半音"（C–#C）是音级语义上的两种半音；在纯律下它们对应不同的频率数值（16:15=111.73c vs 25:24=70.67c），且 #C 本身有二义性。所以"自然/变化"是两套独立定义（音级语义 vs 频率数值），不能混为一谈。
3. 平均律：误差平均化（处处差一点）+ 移调自由；纯律：局部最优 + 整体漂移；五度相生律：五度优先（绝对忠实）+ 三度牺牲（偏 21.51c）。

## Ch08 音程 = 频率比

<a id="ch08"></a>

**选择题**（C、C、C、B、B）：

1. C。大三度 = 4 半音（度数 = 音级差 3，音数 = 半音数 4）。
2. C。转位 $r\mapsto 2/r$ 音分互补，和为 1200。
3. C。三全音 600c 的转位是 1200−600=600c——自己（自互补）。
4. B。复音程 = 单音程 × $2^k$：十二度 = 五度 × 2 = 3:1。
5. B。增四度 45:32 与减五度 64:45 在平均律下重合为同一个三全音；在纯律/五度相生律下数值分裂。

**问答题**：

1. 度数是两个音在音阶上的"第几个到第几个"（音级差），音数是它们之间的半音数。例：C–E 是三度（音级差 2）同时是 4 半音。一个偏重音阶位置、一个偏重半音数目。
2. 第 n 个谐波 $nf_1$ 是基频的 n 倍频率，n 每加 1 相当于音程上跨一个八度（谐波比 $n:1$），所以谐波列 $f_1,2f_1,3f_1\dots$ 依次给出八度、八度+五度、八度+四度……这套"自然复音程"正是分音列的名字来源。
3. 增四度（45:32）与减五度（64:45）是音数相同的两种比值，只有在平均律下它们才都等于 600c（三全音）；纯律/五度相生律下两值不同，所以"等音程"只在平均律下严格成立。

## Ch09 协和与不协和

<a id="ch09"></a>

**选择题**（C、A、C、B、B）：

1. C。小二度是粗糙度曲线的全局最高峰（1.28）。
2. A。八度是最低谷（0.18）；纯五度次之（0.40）。
3. C。三全音 = 粗糙度局部峰（0.75），低于小二度但明显高于周围。
4. B。定量判据 = Plomp–Levelt 粗糙度模型（逐音分可算）。
5. B。纯五度的粗糙度 = 0.40（谐波重合得好）。

**问答题**：

1. 两个音的谐波分量逐一配对算"打架"量，纯五度（3:2）的谐波重合得很好、残留的不协和少，所以粗糙度落到低谷 0.40。曲线把"为什么五度协和"变成了可计算的事实。
2. 三全音两侧是大三度（更平滑）与大六度（更平滑），所以它是两峰之间鼓起的局部峰；而小二度落在最陡的峰顶。局部峰说明三全音"比邻居紧张"，但不如小二度刺耳。
3. 教材的分级（完全协和/协和/不协和……）是把粗糙度曲线粗粒化成几档的记法；简单整数比是帮助记忆的启发式；粗糙度曲线是逐音分可算的定量判据，三者是同一事实的三种粒度。

## Ch10 和弦 = 频率比集合

<a id="ch10"></a>

**选择题**（A、B、B、B、B）：

1. A。大三和弦 = 4:5:6。
2. B。属七和弦 = $1:5/4:3/2:16/9$（大三和弦 + 小七度，七音 16:9 而非 7:4）。
3. B。谐波 7（7:4）比 16:9 低 27.26 音分，失谐太明显，不参与属七构造。
4. B。第一转位（六和弦）= 5:6:8；第二转位（四六和弦）= 3:4:5。
5. B。小三和弦 = 10:12:15（根音 10 谐波 = 三音 12 谐波 = 五音 15 谐波）。

**问答题**：

1. 三和弦 = 根音、三音、五音叠置（大三度/小三度 + 纯五度）。命名来自音阶级数与叠置次序：根音是"地基"，三音/五音是它上方三度、五度的两个成员。在频率语言里就是一组频率比集合（4:5:6 等）。
2. 属七和弦含两个"半音吸引子"：导音 B（距主音 C 100c）与七音 F（距 E 100c）。解决时 B→C、F→E 双双收拢，把两个粗糙度峰值放平、钉死主音——这就是"属七必须解决"的声学内容。
3. 转位只是把同一组频率比重新排列（4:5:6 → 5:6:8 → 3:4:5），集合没变，性质就不变。等和弦（如增四/减五在平均律下是同一个音）来自 $\mathbb{Z}_{12}$ 的商结构；纯律/五度相生律下同一格可能对应两个不同频率，记谱重合即失效，所以只对平均律严格成立。

## Ch11 音阶与调式

<a id="ch11"></a>

**选择题**（A、C、B、B、B）：

1. A。自然大调半音序列 = [2,2,1,2,2,2,1]。
2. C。和声小调 = 自然小调升第 7 级（把 7 级抬到距主音 100c），制造导音；代价是出现增二度（3 个半音）。
3. B。五声音阶 = [2,2,3,2,3]，无半音。
4. B。调式 = 半音序列的旋转：同一个序列从不同起点开始，起点即主音。
5. B。小调把 3/6/7 级各低 100c：谐波重合更晚（小调三度 6:5 而非 5:4）、粗糙度更高，所以听感更"暗"。

**问答题**：

1. 音阶是八度内一组离散频率比，主音是它的基准（0 音分处）。序列本身只给出形状，主音给出位置——同一个大调序列从 C 或 G 开始就是不同调。
2. 自然小调第 7 级距主音 200c（无导音吸力）；和声小调把第 7 级升半音到 1100c，距主音 100c——制造出导音，让"解决到主音"有磁性，代价是出现增二度（3 个半音的一跳）。
3. 五声音阶只规定了"哪五个音级"，没有规定它们的精确频率：三分损益、纯律、平均律各给一套数值，都满足"无半音"的形状约束——所以五声音律不唯一。

## Ch12 五度循环与调关系

<a id="ch12"></a>

**选择题**（B、B、A、B、B）：

1. B。五度循环 = $\mathbb{Z}_{12}$ 上的 $+7$ 轨道（生成元 7，走 12 步回原点）。
2. B。关系大小调 = 同音列、主音相距 3 半音（如 C ↔ a）。
3. A。等音调 = 同一个格子（同一音高）的升/降两种记谱，如 F♯ = G♭。
4. B。近关系调 = 五度圈距离 ≤ 2 步、共同音 ≥ 5。
5. B。C 大调的关系小调是 a 小调（同音列、主音 C 下方 3 半音）。

**问答题**：

1. 调要有"用什么音集"（半音序列，决定形状）和"以哪个音为主"（主音，决定位置）两个要素，缺一不可。序列相同但主音不同 → 关系大小调/同宫系统；主音相同但序列不同 → 同主音调式。
2. 同宫系统 = 同一音列、主音不同（如 C 宫 ↔ D 商，同一个五声音列）；同主音调式 = 主音相同、音列不同（如 C 大 ↔ c 小）。一个是"换主音"，一个是"换形状"。
3. 调之间关系近 = 五度圈上距离近 = 音集重叠多。距离 ≤ 2 步的调至少有 5 个共同音（七声音阶只有 2 个音不同），转调时共同音是"平滑过渡"的桥梁。

## Ch13 移调与转调

<a id="ch13"></a>

**选择题**（B、A、B、C、C）：

1. B。移调 = 对数轴平移 $T_\lambda: f\mapsto\lambda f$。
2. A。平移保持一切音程比（相对结构不变，绝对位置变）。
3. B。纯律网格对非平凡移调不封闭：平移后音会漂移 21.51c（普通音差）或 41.06c（三度不闭合）。
4. C。自由移调要求任何音程平移后仍落在同一套格子里，只有均匀网格（十二平均律）满足。
5. C。移调对称性只在十二平均律下严格成立；纯律/五度相生律平移后音程数值会变。

**问答题**：

1. 因为十二平均律的网格对 $T_{2^{k/12}}$ 封闭：任何音平移 k 格后仍落在格点上，所有音程比不变，听感结构完全相同。纯律/五度相生律平移后会漂移（21.51c/41.06c），所以"移调听起来一样"严格说只对平均律成立。
2. 移调 = 整首曲子平移（主音与所有音一起动）；转调 = 曲子不动、换基准点（主音更换，音集随之变化）。一个是平移整个图像，一个是换坐标系原点。
3. 21.51c 来自普通音差（81:80）——纯律同名音两条路径的差；41.06c 来自三度不闭合（三个大三度 ≠ 两个八度）。纯律移调后落到哪套数值取决于路径，所以漂移有两个尺度。

## Ch14 节奏、速度与力度

<a id="ch14"></a>

**选择题**（A、B、B、B、B）：

1. A。4/4 = 每小节 4 拍、以四分音符为一拍（分母 4 是一拍单位，分子 4 是每小节拍数）。
2. B。切分 = 重音偏离时间格点半拍（弱位起、跨强拍）。
3. B。三连音 = 把一拍等分成 3 份（1/3 拍），是非 2 幂等分（连音符）。
4. B。速度从 60 到 120 BPM，每拍从 1 s 变 0.5 s，时间轴压缩一半。
5. B。响度 ∝ 振幅$^{0.6}$（Stevens 幂律）；物理 dB 是线性的，感知响度被压缩。

**问答题**：

1. 节奏把时间轴离散成 $2^{-k}$ 拍的均匀格子，重音周期性地落在格点上（振幅峰循环）——就像频率轴上的"格"，时间轴上也有"格"，音乐就在这两张格上组织。
2. 速度 = 时间轴缩放（×2 BPM = ÷2 每拍时长），移调 = 频率轴平移（×2^{k/12}）。一个是时间的缩放、一个是频率的平移，二者互逆对应，是"时–频镜像"。
3. 耳朵不是线性传感器：物理振幅跨度可达 10⁶，感知响度被压缩成不到 10³（幂律 0.6）。所以音乐只要 pp→ff 几档力度记号就能覆盖巨大动态——感知压缩让"几档够用"成为可能。

## Ch15 调式变音、导音与旋律

<a id="ch15"></a>

**选择题**（A、B、A、B、C）：

1. A。导音距主音 100c（第 7 级 = 1100c）。
2. B。自然小调第 7 级 = 1000c，距主音 200c，没有导音吸力。
3. A。旋律 = $F_0(t)$：时间–频率平面上的一条曲线。
4. B。调式变音 = 把音阶某音沿 12 格临时移动 ±100c（$T_{+1}/T_{-1}$ 的单点版）。
5. C。半音音阶 = 12 格全部走一遍（每步 +100c），只在平均律下各半音相等。

**问答题**：

1. 半音是粗糙度曲线的峰值区（小二度 1.28，全曲线最高）——导音与主音并置是最强的"待解决"状态。解决（1100c→1200c）释放这股紧张，主音因此被"钉死"。
2. 属七和弦的七音 16:9 距主音 100c，和导音一样是主音下方的半音吸引子。解决时导音 +100c 到主音、七音 −100c 到三度，两个半音收拢，把粗糙度峰值放平——"必须解决"由此而来。
3. 音高 = $F_0(t)$ 的值（曲线高度）；音色 = 谐波结构（谱线的粗细/亮度，随 F0 平行升降）；走向/起伏 = $F_0(t)$ 的斜率与极值；高潮 = 曲线局部最高点配合振幅峰。

## Ch16 乐曲赏析：BWV846

<a id="ch16"></a>

**选择题**（B、D、A、A、D）：

1. B。开头琶音比值 = 1、5:4、3:2、2、5:2（C、E、G、C′、E′）。
2. D。G7 = G、B、D、F（大三和弦 + 小七度）。
3. A。解决时导音 B→C、七音 F→E，两个半音向内收拢。
4. A。全曲功能循环 = 主–下属–属–主（T–S–D–T）。
5. D。B–F = 增四度（三全音），是粗糙度曲线 0.75 的局部峰，全曲唯一的"不协和点"。

**问答题**：

1. 因为它几乎只用"琶音"一种织体，就把大三和弦（谐波重合）、五度循环（T–S–D–T 短程旅行）、导音解决（G7→C）全部摊开。把它的和声骨架翻译成频率比和五度圈坐标，几乎零损耗。
2. G7 里既有导音 B（距 C 100c）又有七音 F（距 E 100c），两处半音"待解决"；G 大三和弦只有 B 一处吸力。而且 B–F 的三全音（0.75）比 G–B 大三度更紧张，更需要放平。
3. 低音 F(5)→E(4) 是级进下行，在五度圈上相邻；E 落在主音 C 下方 100c 的"导音位置"，等于让收束的引力提前闪现，最后 4 小节的收束因此更有力。

## Ch99 尾声

<a id="ch99"></a>

**选择题**（C、A、B、D、D）：

1. C。音高的承载者是谐波序列携带的周期 Δf=f0，不是某根谱线——基频缺失仍听到原音高。
2. A。临界带 = 耳蜗的"频域分辨率"尺度，决定掩蔽、粗糙度峰、谐波是否融合。
3. B。21.51c、1.96c 的律制误差小于临界带，人耳"当作"同一音——平均律因此能成立。
4. D。耳朵不是线性传感器，而是对数–幂律传感器（响度 ∝ 振幅$^{0.6}$）。
5. D。同一音的 1、2、3 谐波相距不足一个临界带，被当成"一个音的音色"而非三个音——这是"和弦融合"与"音色"的生理基础。

**问答题**：

1. 基频缺失实验把第 1 个分音去掉、只留 2、3、4……次谐波，人耳仍听到原来的基频音高。它说明"音高 = 基频"是近似，更准确的是"音高 = 谐波序列所携带的周期"——基频只是让周期最直接可见。
2. 耳蜗基底膜上不同位置对不同频率最敏感，形成"频率–位置"地图（tonotopy）；复合振动在膜上同时激起一串对应各频率分量的响应点，就像实时频谱分析。所以耳朵在物理上就把频谱"画"在了基底膜上。
3. 粗糙度的峰值在临界带边界附近（Ch9 的 ds）；两个分量落入同一临界带内时，弱分量被强分量掩蔽。小二度/三全音恰好在临界带边界附近造成最大"打架"，所以刺耳/难听；同音谐波相距不足临界带则被融合成音色，律制误差小于临界带则"当作"同一音——背后是同一张耳蜗分辨率图。
